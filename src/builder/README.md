# ETF Builder Backend API

A FastAPI-based backend for the "Build Your ETF" application that optimizes ETF portfolios based on desired country and industry allocations.

## Overview

This backend provides two main functionalities:

1. **ETF Listing API**: Browse and filter available ETFs with their distributions
2. **Portfolio Optimization**: Find the optimal combination of ETFs to match your desired allocations

## Features

- RESTful API with automatic OpenAPI documentation
- Country and industry-based ETF allocation optimization
- Filtering and sorting of ETFs by various criteria (TER, fund size, currency)
- Mathematical optimization using scipy for accurate portfolio matching
- Async/await support for high performance
- CORS enabled for web frontend integration

## API Endpoints

### Core Endpoints

- `GET /` - API information and available endpoints
- `GET /etfs` - List ETFs with filtering and sorting options
- `GET /etfs/{etf_id}` - Get detailed information about a specific ETF
- `POST /optimize` - Optimize portfolio based on desired allocations
- `GET /countries` - Get list of all available countries
- `GET /industries` - Get list of all available industries
- `GET /health` - Health check endpoint

### Query Parameters for `/etfs`

- `sort_by` - Field to sort by (ter, fund_size_millions, name)
- `sort_order` - Sort order (asc, desc)
- `limit` - Number of results (1-200, default: 50)
- `offset` - Pagination offset
- `min_fund_size` - Minimum fund size in millions
- `max_ter` - Maximum TER (e.g., 1.0 for 1%)
- `currency` - Filter by currency (USD, EUR, GBP, etc.)

## Running the Server

### Local Development

```bash
# Install dependencies
uv sync

# Run server
uv run python src/builder/server.py
```

Or with uvicorn directly:

```bash
PYTHONPATH=/path/to/project uv run uvicorn src.builder.main:app --host 0.0.0.0 --port 8000 --reload
```

### Production Deployment

For production deployment on Render:

```bash
# Build command
uv sync

# Start command  
uv run python src/builder/server.py
```

Environment variables:
- `PORT` - Server port (default: 8000)
- `HOST` - Server host (default: 0.0.0.0)
- `WORKERS` - Number of worker processes (default: 1)
- `RELOAD` - Enable auto-reload for development (default: false)

## Database Requirements

The API requires:
- `etf_data.sqlite` - SQLite database with ETF distributions
- `data/etfs.json` - ETF metadata in JSON format

These are generated by the scraper and processor components.

## Architecture

The backend consists of several modules:

- `main.py` - FastAPI application and route definitions
- `models.py` - Pydantic models for request/response validation
- `database.py` - Async database operations and ETF data access
- `optimizer.py` - Mathematical optimization using scipy
- `server.py` - Production server startup script

## Optimization Algorithm

The portfolio optimization uses quadratic programming to minimize the difference between desired and achieved allocations while considering:

1. **Country allocation matching** (highest priority)
2. **Industry allocation matching** (medium priority)  
3. **TER minimization** (low priority)

The algorithm ensures diversification by limiting individual ETF allocations to 50% maximum.
